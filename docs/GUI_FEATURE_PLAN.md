> 目标：把当前 ImGui 前端（`src/gui/main_gui.cpp`）补齐到 `docs/image.png` 所示"正式版"
> EasyTshark 的功能集。约束沿用项目既定：**C++11**、仅本地构建、UI 只经
> `AnalysisSession` 门面访问核心库（同进程"核心库 ↔ UI"边界，非网络 C/S）。
>
> **用户决策（2026-07-24）**：
> 1. **布局不照搬图片**——保留当前 Tab 风格布局（用户认为现在的观感很舒服），
>    只在其上"增加缺失的功能和显示"，不重构成侧边栏+工具栏的刚性布局。
> 2. **范围**：第一期尽量整期做完；**第二期全做**（协议分层树 / tshark `-Y` 过滤 /

## 一、正式版界面盘点（docs/image.png）

- **顶部工具栏**：首页、开始抓包、停止抓包、分析文件、保存。
- **左侧导航树**（三大类）：
  - 数据包：全部数据包 / ARP / ICMP / ICMPv6
  - 通信会话：TCP会话 / UDP会话 / DNS会话 / HTTP会话 / SSL-TLS会话 / SSH会话 / 进程分析
  - 统计分析：IP统计 / 协议统计 / 国家统计
- **过滤栏**：过滤表达式输入框 + "查找"按钮。
- **报文表格**（列更丰富、可排序）：时间、源IP/源Mac、源IP归属地、源端口、
  目的IP/目的Mac、目的IP归属地、目的端口、协议（彩色徽标）、数据包大小、信息。
  行内含国家旗标、"内网"标签、设备图标。
- **分页**：共 N 条、页码 1–5…50、每页条数选择器。
- **底部详情面板**：可展开的协议分层树（以太网 II / IPv4 / TCP）。
- **底部 Hex 面板**：offset + hex + ASCII。
- **状态栏**：数据包总数、总字节数、空闲中、关于。

## 二、当前 GUI 已有

- 控制条：离线载入路径输入 + 载入分析；实时抓包（刷新网卡 / 选网卡 / 开始 / 停止）。
- Tab「报文」：7 列表格（No./时间/源/目的/协议/长度/概要）+ 右侧详情键值表 + Hex。
- Tab「查询」：MAC/IP/端口/归属地 结构化模糊查询，结果为 JSON 文本。
- 后端：`AnalysisSession` 门面已提供 载入、报文快照、getHex、参数化查询、实时抓包、
  导出 PDML JSON、网卡列表、流量趋势（`FlowMonitor` 暂无 UI 消费）。

## 三、差距清单与实现路径

按"是否需要新增后端能力"分层。**T** = 纯前端；**B** = 需核心库新增。

| # | 功能 | 类型 | 说明 / 后端改动 |
|---|------|------|-----------------|
| 1 | 顶部工具栏（分析文件/开始/停止/保存/首页） | T | 把现有分散按钮收敛为顶部一行工具栏；"分析文件"触发文件路径载入；"保存"= 复制当前 pcap 到用户指定路径（已有 `pcapPath()`） |
| 2 | 左侧导航树 + 主区联动 | T | 新增 `AppState::navSelection` 枚举；`ImGui::TreeNode` 三级树；点击切换主区视图 |
| 3 | 报文表格列扩展（源IP/Mac 合并、双归属地、双端口、大小） | T | Packet 已含全部字段，仅前端加列 |
| 4 | 协议彩色徽标 | T | 前端按协议名映射颜色（TCP/UDP/DNS/TLS/HTTP/ICMP/ARP…） |
| 5 | "内网"标签 / 国家旗标 | T(部分) | "内网"：前端判断私有网段即可；国家旗标：ASCII 暂以国家名文本代替（旗帜位图后续再议） |
| 6 | 协议快速过滤（全部/ARP/ICMP/ICMPv6） | T | 前端对 `packets` 按 `protocol` 前端过滤即可，无需后端 |
| 7 | 过滤表达式栏 + 查找 | B(轻) | 先做前端子串/多字段过滤；进阶：新增 `AnalysisSession::queryDisplayFilter()` 透传 tshark `-Y`（列入二期） |
| 8 | 分页（共N条 / 页码 / 每页条数） | T | 前端对已加载 `packets` 分页切片；clipper 仍用于单页渲染 |
| 9 | 协议分层树详情（PDML） | B | 新增 `AnalysisSession::getPacketDetailTree(frame)`：对单包跑 tshark `-T pdml`/`-V` 或复用 `PdmlToJsonConverter`，返回可展开层级 |
| 10 | 会话视图（TCP/UDP/DNS/HTTP/SSL-TLS/SSH） | B | 新增会话聚合：对 `packets` 按五元组归并（前端可算 TCP/UDP 会话）；DNS/HTTP/TLS/SSH 需按协议过滤 + 概要，属协议级会话，先做 TCP/UDP，其余二期 |
| 11 | 进程分析 | B | 依赖本机 socket→pid 映射（macOS 需 `lsof`/私有 API），跨平台成本高，**列入后期，本期占位禁用** |
| 12 | 统计分析（IP/协议/国家统计） | T | 对 `packets` 前端聚合计数（IP 出现次数、协议分布、归属地/国家分布），表格 + 计数展示 |
| 13 | 状态栏（总数/总字节/状态/关于） | T | 前端累加 `len`；"关于"弹窗 |

## 四、分期实施顺序

### 第一期（纯前端，先出效果，全部 T 类 + 轻量）
1. **布局重构**：顶部工具栏 + 左侧导航树 + 右侧主区 + 底部详情/Hex + 底部状态栏。
2. **报文表格增强**：完整列、协议彩色徽标、"内网"标签、归属地列。
3. **协议快速过滤**：导航树"数据包"分类（全部/ARP/ICMP/ICMPv6）前端过滤。
4. **分页**：每页条数选择 + 页码切换。
5. **统计分析**：IP统计 / 协议统计 / 国家(归属地)统计，前端聚合。
6. **会话视图（TCP/UDP）**：前端按五元组聚合。
7. **过滤表达式栏**：前端多字段子串匹配版。
8. **状态栏 + 保存 + 关于**。

### 第二期（需后端新增，逐项加）
9. **协议分层树详情**：`AnalysisSession::getPacketDetailTree(frame)`（PDML → 层级）。
10. **过滤表达式透传 tshark `-Y`**：`queryDisplayFilter()`。
11. **DNS/HTTP/SSL-TLS/SSH 会话**：协议级会话聚合。

### 后期（跨平台成本高）
12. **进程分析**：socket→pid 映射，本期界面占位并禁用。
13. **国家旗帜位图**：先用国家名文本占位。
